Relay.

Move visual work between the browser and Figma without rebuilding it by hand. Browser → Figma uses native Figma clipboard data; Figma → HTML uses the companion local plugin.

The URL loader fetches HTML and re-renders it locally. For JS-heavy pages, the bookmarklet attempts capture inside the live page so computed styles reflect the current state.

What is actually native?

For HTML/SVG, Relay delegates DOM → Figma conversion to @figit/dom-to-figma. It reads computed styles and emits the binary clipboard payload Figma itself accepts.
