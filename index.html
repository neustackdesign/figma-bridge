Move visual work between the browser and Figma without rebuilding it by hand. Browser → Figma uses native Figma clipboard data; Figma → HTML uses the companion local plugin.

local-first · no account
Script-backed HTML is rendered at a fixed 1440 × 900 viewport. Figma Bridge scrolls through the page to trigger reveal/lazy-load states, returns to the top, freezes motion, then converts the full document. The preview is visually scaled only; scaling does not change the source viewport.
URL import uses returned server HTML. For JS-rendered sites, use the bookmarklet on the live page.
