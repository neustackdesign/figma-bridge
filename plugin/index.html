The reverse half of Figma Bridge is a local development plugin. Keep these three files together, import the manifest in Figma Desktop, then export selected frames as one self-contained HTML file.

What the exporter preserves. Auto Layout becomes CSS flex, text stays editable, vectors become inline SVG, image fills are embedded, and unsupported complex layers rasterize only as a fallback.
